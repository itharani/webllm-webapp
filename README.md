# WebLLM Web App

This project is a web application built using **Vite** as the development server and bundler. It integrates with WebLLM for machine learning model capabilities and provides a user-friendly interface for working with machine learning models in the browser.

## Features
- **Fast Development**: Built with Vite for quick development and hot-reloading.
- **Lightweight**: Easy to run on modern browsers without heavy dependencies.
- **WebLLM Integration**: Powered by WebLLM to enable local model usage.

## Prerequisites
Ensure the following are installed on your system:
- [Node.js](https://nodejs.org/) (v16 or later)
- npm (comes with Node.js)

## Installation

### 1. Clone the Repository:
Clone the project to your local machine using Git:

```bash
git clone https://github.com/itharani/webllm-webapp.git
cd webllm-webapp
```

### 2. Install Dependencies: 
Install the required dependencies with npm:
```bash
npm install
```

### 2. Running the Application: 
 Launch the app locally using the Vite development server:
```bash
npm start
```
